# Фотографии течей масла на оборудовании (`yollo-ML`)

Цель набора — **70 уникальных реальных фотографий**, а не 70 результатов поиска.
Ветка: `ML-tests`. Путь `yollo-ML` — по запросу владельца.

**Текущий статус: 0 из 70 подтверждённых фотографий.**
Папка создана и подготовлена: загрузчик, воркфлоу и правила отбора на месте.
Пока ни одна фотография не прошла визуальную проверку и проверку лицензии,
поэтому в `images/` пусто — это честный недобор, а не подбор «чего попало».

## Что допускается

- Видимое масло, масляный потёк или капля на двигателе, редукторе, насосе,
  гидравлическом шланге, трубе, фланце или другом оборудовании.
- Подтверждённая открытая лицензия именно на изображения с правом распространения.
- Явный визуальный отбор, источник, автор и основание считать жидкость маслом.
- Оригинал JPEG/PNG/WebP с короткой стороной не менее 256 px.

Не допускаются вода/топливо/антифриз, морские разливы, просто пятна на земле,
чистое оборудование, схемы, коллажи, синтетика, аугментации ради количества,
дубликаты и фотографии с неизвестными правами. Название статьи или метка класса
сами по себе не доказывают, что на каждом снимке есть подходящая течь.

## Хранение и загрузка

Фотографии скачивает **только GitHub-hosted runner** через
`.github/workflows/collect-oil-leaks.yml`. На ноутбук фотографии не загружаются.
Скрипт `tools/collect_oil_leaks.py` отказывается выполнять загрузку локально.
В `main` эти изменения не вносятся.

- `sources/approved.json` — только явно отобранные фотографии с лицензиями.
- `sources/research.md` — исследованные источники и причины отклонения.
- `images/` — оригинальные изображения, появится после успешного отбора и загрузки.
- `manifest.json` — происхождение, лицензия, размер, SHA-256 и perceptual hash.
- `ATTRIBUTION.md` — атрибуция каждого оригинала.
- `reports/collection.json` — фактическое количество и недобор до 70.

Если подходящих открытых фотографий меньше 70, набор остаётся неполным.
Результаты поиска не выдаются за визуально проверенные изображения.

## Важно для YOLO

Это сбор фотографий, **не готовый обучающий датасет object detection**.
Случайные или полноэкранные bounding boxes не создаются. Для обучения детектора
нужно разметить видимые области течей (например, класс `oil_leak`) в CVAT/Label Studio,
проверить разметку и разделить train/val/test по оборудованию/съёмке, а не по похожим кадрам.
Негативные примеры следует собирать и маркировать отдельно, не смешивая их с положительными.

Лицензия кода или API источника не заменяет лицензию фотографий. CC-BY-SA-файлы
сохраняют собственные условия; лицензии отдельных изображений не переопределяются
лицензией проекта.
