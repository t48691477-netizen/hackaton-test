# Проверка источников

Поиск ведётся по направлениям: двигатели, гидравлика, трубопроводы/промышленное оборудование.
Цель — 70 уникальных фотографий с открытыми лицензиями.

## Статус на 2026-11-14

- Найденные страницы и наборы **не считаются автоматически одобренными**.
- Wikimedia Commons: просмотрены отранжированные превью; почти всё — морские
  разливы, схемы, чистое оборудование или кадры поиска течи без самой течи.
- Roboflow `digitele/oil-leakage` — лицензия проекта CC BY 4.0, но кадры
  отбираются по видимой течи; часть — дубликаты.
- Roboflow `tryout/oil-leak` — в сохранённых метаданных лицензия не указана,
  поэтому кадры из него не включаются без отдельного подтверждения прав.
- Фотографии в репозиторий пока не загружены: 0 из 70 прошли полную проверку.
