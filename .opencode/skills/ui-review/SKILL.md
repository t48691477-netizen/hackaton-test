# Ревью дизайна AR-Инспектора

Цель: не дать интерфейсу вернуться к «строительному» виду и не дать ушам
дизайна испортить работу рукой в перчатке.

## 2. Что уже было «так нельзя»

- Угловые скобки-визиры на панелях (`hudFrame` со `cornerLength`) — выглядело
  как видоискатель на каждом блоке. Сейчас карточка = скругление 14 dp + линия
  + смысловая полоса слева.
- Сигнальный жёлтый как основной цвет. Остался только у `Warning`.
- Моноширинный шрифт у всего подряд. Теперь моно — только цифры, ID и «шильдики».

## 3. Чек-лист перед коммитом

1. **Контраст.** Текст на фоне ≥ 4.5:1, крупный (≥ 19 sp) ≥ 3:1. Проверь
   `TextMid` на `InkCard` — это самый частый провал.
2. **Цели.** Любая нажимаемая цель ≥ 48 dp, главная кнопка ≥ 72 dp.
   Расстояние между соседними мишенями ≥ 16 dp.
3. **Правая рука.** Главное действие — в нижней правой дуге. Ничего
   критичного в верхних 25% экрана.
4. **Статус читается без цвета.** Каждый статус — форма/иконка + текст. Если
   перевести скриншот в ч/б и статус стал неясен — переделай.
5. **Один акцент на экран.** Если на экране три разных ярких цвета —
   вернись и реши, какой из них главный.
6. **Скругления.** 10–14 dp для карточек, 999 для пилюль, полный круг для
   круглых кнопок. Не мешай 4 dp и 28 dp в одном блоке.

## 4. Как самому увидеть результат

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n ru.cyber102.arinspector/.MainActivity --es equipment_id PUMP-402
```

Скриншот: `adb shell screencap -p /sdcard/s.png && adb pull /sdcard/s.png .`
