# Дизайн-концепт: «Промышленный HUD»

Тёмный интерфейс, моноширинные подписи, жёлтый «предупреждающий» акцент и бирюзовые
технические элементы. Ощущение: прибор инженера, а не потребительское приложение.

увеличенным `letterSpacing` (эффект шильдика).

## Визуальные приёмы

1. **Угловые скобки на панелях** (`Modifier.hudFrame`) — рамка с утолщёнными
   уголками, как в видоискателе. Дёшево в коде, дорого выглядит.
2. **Нумерованные секции** `01 / 02 / 03` — задают порядок действий в BottomSheet.
3. **Бегущая линия сканирования** на экране QR и пульсирующие окружности во время
   ИИ-анализа — интерфейс «живой», даже когда сеть думает 1.5 секунды.
4. **Статусные пилюли** вместо текста статуса: `DEMO`, `SIM AR`, `CRITICAL`,
   `HIGH`. Читаются с последнего ряда зала.
5. **Плашки узлов в 3D** — тёмная подложка, цветная полоса слева, точка-индикатор.
   Красная плашка = дефект, жёлтая = предупреждение, циан = норма.

## Идеи, которые стоит добавить (по возрастанию сложности)

1. **Рентген-режим**: тап по узлу временно делает остальные маркеры прозрачными,
   оставляя только выбранный и его дефекты. Ощущение «я вижу сквозь оборудование».
2. **Тепловая карта риска**: маркеры красятся не по факту дефекта, а по
   вероятности (`confidence × severity`) — сцена превращается в карту состояния.
3. **Мини-радар**: в углу экрана круговая схема узлов сверху, точки подсвечиваются
   при обнаружении дефекта. Помогает, когда часть маркеров вне кадра.
4. **Таймлайн осмотра**: лента «13:40 — трещина корпуса · 13:41 — коррозия фланца»
   под кнопкой сканирования. На защите показывает, что приложение ведёт журнал.
5. **Режим «до/после»**: после акта — тот же кадр с зелёными галочками на местах
   устранённых дефектов. Сильный визуальный финал питча.
6. **AR-стрелка к дефекту**: если дефект за пределами экрана, по краю рисуется
   стрелка с расстоянием до узла — «иди туда».
7. **Печать акта с QR**: PDF содержит QR на запись в системе — проверяющий сканирует
   и видит статус. Замыкает цикл «бумага → цифра».

## Как переносить бумажный макет

1. Фото листка → разметить блоки (шапка / сцена / нижняя панель / шит).
2. Для каждого блока определить: цвет фона, акцент, наличие скобок, тип текста.
3. Сопоставить с готовыми компонентами: `HudPanel`, `StatusPill`, `SectionTitle`,
   `PrimaryAction`, `SegmentedChoice`, `ConfidenceBar`.
4. Новые элементы оформлять через `Modifier.hudFrame` и палитру из `ui/theme/Color.kt`,
   чтобы не появилось «ещё одного» стиля.
