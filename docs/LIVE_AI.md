# Подключение к реальным моделям

Приложение **никогда** не обращается к внешним AI-провайдерам напрямую.
Схема одна:

```
Android (Retrofit) → backend/server.py → vision/LLM провайдер
```

Ключ живёт только на сервере. APK распаковывается за 10 секунд — в нём нет
и не должно быть ни одного токена.

## 1. Режимы бэкенда

| Режим | Когда | Что отдаёт |
|---|---|---|
| `mock` (по умолчанию) | нет переменных окружения | заранее подготовленные дефекты, `model: mock-vision` |
| `live` | заданы `LLM_BASE_URL` + `LLM_API_KEY` | реальный ответ модели, `model: <LLM_MODEL>` |

Приложение не меняется. Бейдж в шапке AR-сцены сам переключается
`DEMO` → `LIVE AI` (по `GET /api/health`).

## 2. Включение live-режима

Бэкенд говорит по OpenAI-совместимому контракту `POST {LLM_BASE_URL}/chat/completions`
с изображением `data:image/jpeg;base64,…`. Это работает с OpenAI, OpenRouter,
Together, vLLM, Ollama (`/v1`) и большинством корпоративных шлюзов.

PowerShell:

```powershell
$env:LLM_BASE_URL = "https://api.openai.com/v1"
$env:LLM_API_KEY  = "sk-..."          # только в текущей сессии
$env:LLM_MODEL    = "gpt-4o-mini"     # модель с поддержкой изображений
$env:LLM_TIMEOUT  = "45"
python backend/server.py
```

Проверка:

```powershell
curl http://localhost:8080/api/health
# {"status":"ok","mode":"live","model":"gpt-4o-mini",...}
```

## 3. Что делает бэкенд

`POST /api/inspect`:

1. Собирает промпт с паспортом оборудования и списком узлов.
2. Отправляет кадр в модель.
3. Парсит строгий JSON (`bbox` в долях 0..1), нормализует координаты и
   превращает `bbox` в `polygon`, чтобы приложение рисовало оверлей.
4. Считает общий `status` по худшей критичности.
5. **При любой ошибке** (сеть, ключ, кривой JSON) тихо отдаёт mock-ответ —
   демо не падает в самый неудачный момент.

`POST /api/chat` — ассистент «Моттэл»: тот же ключ, отдельный промпт
(инженерная роль, короткие ответы, история последних 8 реплик).

## 4. Если провайдер не OpenAI-совместимый

Адаптер один — `call_llm()` в `backend/server.py`. Для другого формата
(например, Gemini `generateContent` с `inline_data`) достаточно заменить тело
этой одной функции; контракт `/api/inspect` и приложение не трогаются.

## 5. Правила безопасности

- `.env`, `local.properties`, ключи — в `.gitignore`, в репозиторий не попадают.
- Ключ не в `BuildConfig`, не в `strings.xml`, не в `gradle.properties`.
- На аккаунте провайдера — лимит расходов.
- Если ключ случайно попал в коммит: отозвать ключ, затем чистить историю
  (`git filter-repo`). Простой `git rm` ключ из истории не убирает.
