# Набор фотографий течей масла

Собрано **3 из 70** подтверждённых фотографий; недобор — **67**.
В `yollo-ML/` находятся фотография протекающего трансформатора, фотография
двигателя MUSTAD MARINE и фотография коробки передач GTi-6. Папка содержит
только эти три JPEG.

Каждый файл проверен визуально, открыт как JPEG и проверен по минимальной
стороне (не менее 256 px). Для каждого файла рассчитан SHA-256; сравнение pHash
не обнаружило близких дублей. Страница Commons подтверждает масляную утечку на
трансформаторе; отдельные записи Flickr подтверждают фотографии двигателя и
редуктора.

Полные авторство, страницы-источники, лицензии, размеры и SHA-256 приведены в
[`manifest.json`](manifest.json). Краткая атрибуция и условия распространения —
в [`ATTRIBUTION.md`](ATTRIBUTION.md). История поиска — в [`research.md`](research.md).

Разметка областей течи не создавалась. Набор не является готовым датасетом
детекции объектов; перед обучением нужны разметка, проверка разметки и разбиение
по оборудованию/съёмке. Изображение редуктора под CC BY-SA 2.0 сохраняет
собственные условия лицензии. Загрузчик и workflow из репозитория сохранены;
эти три файла проверены и добавлены непосредственно в целевую папку.
