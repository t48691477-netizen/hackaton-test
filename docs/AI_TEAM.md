## 🎯 Что мы делаем

**Экран 1 — Сканер.** ML Kit Barcode Scanning читает QR вида `PUMP-402`,
приложение делает `GET /api/equipment/PUMP-402` и открывает AR.

**Экран 2 — AR-сцена.** Плоскость с QR — базовый якорь (0,0,0). По массиву
`components[].offset_from_qr` расставляются 3D-маркеры (сфера + плашка с названием).
Кнопка «Запустить ИИ-сканирование» снимает кадр → `POST /api/inspect`.
Ответ содержит нормализованные полигоны: ржавчина заливается красным, трещины — рамками.
Если `status == high` или дефект в радиусе узла — маркер узла краснеет.

**Экран 3 — Карточка/акт.** BottomSheet: узел, дефект, инженерный анализ LLM,
статус (Исправлено на месте / Требует заказа запчастей / Ложное срабатывание),
кнопка «Зафиксировать акт» → `POST /api/reports`.

Стек: **Kotlin + Jetpack Compose + ML Kit + SceneView/ARCore + Retrofit**.

## 🧭 Правила игры

- **Не ломать контракт API** без обновления `docs/API.md`.
- **Один экран — один пакет** (`ui/scanner`, `ui/ar`, `ui/result`). Не тащить всё в MainActivity.
- **Демо важнее красоты кода.** Приложение обязано работать без бэкенда (Demo mode).
- **Никаких секретов в репозитории.** Токены, ключи, `local.properties` — только локально.
- **Коммиты** — маленькие, по одной фиче. Ветки: `feat/...`, `fix/...`, `design/...`.
- **Перед пушем** — `./gradlew assembleDebug` должен быть зелёным.
- **Не перезаписывать чужие файлы** без чтения. Сначала `git status`, потом правки.
