# 🏭 Промышленная система ТОиР: Инспекция оборудования (YOLO + LLM)

Интеллектуальный бэкенд предиктивной аналитики и детекции дефектов оборудования (ТОиР) на базе **FastAPI**, **YOLOv11-seg** (коррозия), **YOLOv8-det** (сварные швы и трещины) и **LLM** (Главный эксперт ТОиР).

---

## 🚀 Быстрый старт

### 1. Запуск сервера API
В папке проекта `D:\hackaton_26`:

```bash
python run.py
```

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Сервер запустится на `http://localhost:8000`.

### 2. Документация и схемы Pydantic
* **Интерактивный Swagger UI**: [http://localhost:8000/docs](http://localhost:8000/docs)
* **ReDoc**: [http://localhost:8000/redoc](http://localhost:8000/redoc)
* **Спецификация OpenAPI для разработчиков фронтенда и мобилки**: [http://localhost:8000/openapi.json](http://localhost:8000/openapi.json) (также сохранен локально в `D:\hackaton_26\openapi.json`).

## 🧠 Архитектура пайплайна

```
[ Фото узла ] ──> [ Decizez/yolov-corrosion-detection ] ──> Маски коррозии
       │
       └───────> [ avinashhm/welding-defect-yolov8 ]   ──> Боксы дефектов сварки/трещин
                                 │
                                 ▼
                     [ YOLOOutputConverter ]
                     - Маски: [[x, y], ...] (нормализованные 0.0 - 1.0)
                     - Боксы: [x_min, y_min, x_max, y_max]
                                 │
                                 ▼
                     [ Главный эксперт ТОиР (LLM) ]
                     - Вход: имя оборудования, возраст узла, дата ТО, дефекты
                     - Выход: JSON (criticality, probable_cause, recommendations)
                                 │
                                 ▼
                    [ /api/inspect Response ]
```

## 📡 Эндпоинты API

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/api/equipment` | Полный список оборудования со статусами |
| `GET` | `/api/equipment/{id}` | Детальная карточка агрегата с узлами и датами ТО |
| `POST` | `/api/equipment` | Создание или обновление агрегата (для веб-интерфейса) |
| `POST` | `/api/inspect` | Прием фото + `equipment_id`, инференс YOLO + LLM эксперт |
| `POST` | `/api/reports` | Сохранение официального акта осмотра и статуса ремонта |
| `GET` | `/api/reports` | Журнал актов для диспетчера (с фильтрами по статусу и ID) |

## 📐 Формат вывода конвертера YOLO

### Сегментация (маски)
Маски конвертируются в список точек `[x, y]` в **нормализованных координатах** `[0.0, 1.0]`:
```json
"polygon": [
  [0.3255, 0.3733],
  [0.3333, 0.4812],
  [0.3793, 0.4816]
]
```

### Детекция (боксы)
Боксы возвращаются в формате `[x_min, y_min, x_max, y_max]`:
* `bbox`: в абсолютных пикселях `[263.62, 403.12, 307.24, 520.16]`
* `bbox_normalized`: в относительных координатах `[0.3255, 0.3733, 0.3793, 0.4816]`

## 🤖 Системный промпт Главного эксперта ТОиР

Промпт задает роль опытного промышленного инженера-диагноста:

```text
Ты — Главный эксперт по техническому обслуживанию и ремонту (ТОиР) промышленного оборудования и опасных производственных объектов с опытом более 25 лет.
Твоя задача — проводить глубокий предиктивный и диагностический инженерный анализ дефектов (очаги коррозии, дефекты сварных соединений, трещины, усталостные повреждения), обнаруженных системами машинного зрения на агрегатах.

ТВОИ ПРАВИЛА:
1. Анализируй дефекты с учетом типа оборудования, возраста узла, даты последнего планового ТО и уверенности нейросетей.
2. Определи уровень критичности (criticality):
   - "high": наличие трещин, глубокая язвенная/щелевая коррозия, дефекты сварных швов (Bad Weld) на несущих или напорных узлах, создающие риск разрушения, аварии или внепланового останова производства.
   - "medium": умеренная коррозия, поверхностные поры или непровары, требующие устранения при ближайшем планово-предупредительном ремонте (ППР).
   - "low": начальные поверхностные следы окисления, незначительные отклонения, не угрожающие целостности агрегата в текущем межремонтном интервале.
3. Четко обоснуй физико-механическую и эксплуатационную причину возникновения дефекта (probable_cause) с привязкой к возрасту узла и сроку с последнего ТО.
4. Предоставь конкретную пошаговую инженерную рекомендацию (recommendations) в виде списка действий.
```

Формат строгого JSON на выходе:
```json
{
  "criticality": "high",
  "probable_cause": "Кавитационная эрозия с последующим электрохимическим коррозионным поражением металла...",
  "recommendations": [
    "1. Ограничить эксплуатационную нагрузку на 30%...",
    "2. Выполнить ультразвуковой контроль (УЗК) по ГОСТ 14782-86...",
    "3. Произвести зачистку до степени Sa 2.5...",
    "4. Выполнить повторную заварку с предварительным подогревом до 150°C...",
    "5. Нанести эпоксидный цинконаполненный защитный состав."
  ]
}
```
